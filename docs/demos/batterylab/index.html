    Methodology and scope

    The engine simulates a price-taking wholesale battery over one complete NEM market day (288 contiguous five-minute intervals, fixed UTC+10). For each interval, grid imports c and exports d (MWh) satisfy:

    E[t] = E[t−1] + ηc·c[t] − d[t]/ηd
c[t] ≤ min(charge MW, import limit)·dt    d[t] ≤ min(discharge MW, export limit)·dt
E_min ≤ E[t] ≤ E_max    c[t] = 0 or d[t] = 0    E[last] = E_initial

    Fixed schedule allocates the largest feasible single charge-then-discharge excursion across the configured windows without looking at prices. Perfect hindsight maximises margin over the same windows and constraints; the demo reports it optimal only when an independently evaluated dual bound certifies the gap within AUD 0.01.

    margin = Σ price·d − Σ price·c − import_fee·Σc − export_fee·Σd − degradation·Σd

    Negative purchase prices are a credit; efficiency losses are a physical quantity, never charged twice. Excluded: capital/finance costs, contracts, network charges and loss factors, FCAS and retail tariffs. Results are a simulated energy-trading margin — not investment return or actual facility revenue.
