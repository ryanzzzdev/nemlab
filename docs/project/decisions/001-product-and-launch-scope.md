# 001 — Product and launch scope

Date: 2026-09-13  
Status: Accepted

## Context

NEMLab combines historical NEM analysis and battery experiments in one portfolio project.

## Decision

Focus on NEM. Deliver BatteryLab first, then GridReplay before public launch. Assess Admin before launch; its UI may be deferred while critical operator controls still ship.

## Alternatives

Launching BatteryLab alone was the earlier recommendation. The user explicitly changed the sequence to include GridReplay before launch. WEM and additional explorers remain deferred.

## Consequences and follow-up

The public release has two product journeys and shared data requirements. Keep internal milestone completion separate from public launch.

## Acceptance source

User chose NEMLab/NEM scope in the idea discussion and explicitly revised steps 4–6 in the implementation conversation. Recorded 2026-09-13.
